# MASHINA 32+96 — clean installation test

Use one FM1. No intermediate firmware or initialized storage is required. Previous contents are not migrated. Export any sounds you wish to keep before installing (optional). Existing user data is erased during explicit initialization.

Extract the whole artifact, start `py -m http.server 8000` in the extracted directory, open http://localhost:8000/webapp/installer/ in Chrome, and install. After flashing, open http://localhost:8000/web-library/initialize.html . Connect, type ERASE THIS FM1, confirm Initialize storage, and power-cycle on success. Exactly 69 sectors: 32 project, 24 library, 6 USER/companions and 7 auxiliary. A distinct MPS2 project-bank marker prevents old MPS1 storage from unlocking writes. Normal writes unlock only after initialization and reboot. No automatic format on boot. Old content need not be valid.

Open http://localhost:8000/web-library/ . Connect, capture and verify the new complete backup. Expect 32 empty USER, 96 factory LIBRARY, 8 empty projects (A–D). Test MIDI PC 0,31,32,63,64,95,121,127; blank USER should not change sound. Save disposable USER presets; transfer sounds to LIBRARY 065, 096, 128 and test reboot, sound/name, drum/FM6 companions, project references, overwrite and factory reset. Back up and restore same-geometry data. Old sound packs can be imported; 32-slot complete snapshots cannot be restored wholesale to 96 slots. No public deployment or merge before physical validation.
