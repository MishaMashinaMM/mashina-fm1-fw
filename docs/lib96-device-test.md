# MASHINA 32+96 — automatic clean installation test

Use one FM1. No intermediate firmware, old data compatibility or mandatory backup is required. Export any sounds you want to keep (optional). The installer warns before flashing. A different firmware or incompatible MASHINA layout starts clean; reinstalling the same or compatible layout retains user data.

Extract the entire artifact, start `py -m http.server 8000` in its folder, open http://localhost:8000/webapp/installer/ in Chrome and install. Keep the FM1 powered through first boot. The updater identifies the previous storage ABI via the app directory tag and invalidates only bank-zero's two markers when transitioning from a different ABI. First boot initializes the 69 owned sectors automatically before loading old data, commits MPS2 last, and proceeds with normal operation. No separate initialization page. If first boot is interrupted, the next boot completes the initialization; if a storage error is displayed, power-cycle and report persistent errors.

Open http://localhost:8000/web-library/ and connect. Expect 32 empty USER, 96 factory LIBRARY, 8 empty projects (A–D) after an incompatible install. Capture the new complete backup as part of testing transfers. Test PC 0,31,32,63,64,95,121,127, USER saves, LIBRARY 065,096,128 transfer/read-back/reboot, drum/FM6 companions, project references, overwrite and factory reset. Reinstall the same package after saving disposable presets/projects and confirm they survive. Offline compatible sound packs may be imported. No public deployment or merge before physical validation.
