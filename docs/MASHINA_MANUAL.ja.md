# MASHINA — FM1 ユーザーマニュアル

MASHINA は M-VAVE FM1 を外部 MIDI キーボード、パッド、コントローラー向けの 6 トラック音源にします。ライブで使う操作を説明します。

## 1. 操作と画面移動

**HOME** はホームへ戻り、長押しで設定メニューを開きます。**GLO** はミキサーと全体設定、**EDIT** は音源の編集、**ENV / LFO / FX** はエンベロープ・変調・エフェクトを開きます。**SAVE** は音色とプロジェクトを保存します。**SEQ** はドラム MIDI マップ、**PLAY** はドラムの演奏設定、**REC** は MIDI マクロです。曲シーケンサーとしては動作しません。

**SELECT** を回してページを移動し、通常は **ALGORITHM** でトラックを選択します。**K1〜K4** が画面上のパラメーターに対応します。**OCT− / OCT+** は内蔵鍵盤のオクターブを変えます。

HOME 長押しのメニューは **SCREEN / AUDIO / MIDI / USB / CONTROLS / SYSTEM**。**AUDIO → TRACKS** で 4 または 6 トラックを指定します。**MIDI → LEARN** は MIDI 学習、**LEARN CLEAR** は割当の消去です。

### 物理操作ボタンの一覧

| ボタン | 機能 |
| --- | --- |
| HOME | ホームに戻る。長押しで設定メニュー。 |
| GLO | ミキサー、MIDI ゾーン、調律、センド、共通 EQ、システム。 |
| EDIT | 選択トラックの音源パラメーター。 |
| ENV | エンベロープと変調先。 |
| LFO | LFO、変調、音色の動き。 |
| FX | トラックエフェクトと全体のエフェクトバス。 |
| SCL / ARP | スケール・コード、アルペジエーター。 |
| SAVE | 音色、プリセット、プロジェクト、ライブラリーの保存管理。 |
| SEQ | ドラムの MIDI ノート・パン・ピッチ設定。曲シーケンサーではありません。 |
| PLAY | ドラムのベロシティ、チョーク、リトリガー。 |
| REC | プロジェクトごとに最大 32 個の MIDI CC マクロ。 |
| ALGORITHM | 通常はトラック選択。画面によって専用機能があります。 |
| SELECT | ページ移動。ドラムではパッド選択。 |
| K1〜K4 | 表示されている 4 つの値を変更。 |
| PRESETS | 通常は音色選択。MIXER などでは別機能。 |
| OCT− / OCT+ | 内蔵鍵盤のオクターブを変更。両方同時に押すと移調をゼロに戻す。 |

基本的にボタンでセクションを開き、SELECT でページを選び、対応する K ノブで値を変更します。変更はすぐに反映されますが、再起動後も残すには**プロジェクトを保存**してください。

### HOME 長押し設定メニュー

| ページ | 主な設定 |
| --- | --- |
| SCREEN | スコープ、画面スリープ、LED の明るさ、スケール LED |
| AUDIO | スピーカー EQ、有効トラック数 4/6、負荷表示、BPM LOCK |
| MIDI | MIDI 出力、MIDI Learn、学習した操作の消去 |
| USB | USB オーディオ、USB 音量 |
| CONTROLS | 長押し時間、ノブ加速、FX latch、キャリブレーション |
| SYSTEM | 最後の状態を復元、CPU コア数・クロック、ABOUT |

SELECT でグループを移動し、該当する K ノブで設定します。HOME で終了。**LEARN CLEAR** は割当を削除するので慎重に確認してください。

## 2. 外部 MIDI とミキサー

互換性のある USB または TRS MIDI コントローラーを接続し、**GLO → MIX → MIXER** を開きます。**ALGORITHM** で T1〜T6 を選びます。

| 操作 | 機能 |
| --- | --- |
| **K1** | MIDI 受信チャンネル **1〜16** |
| **K2** | トラック音量 |
| **K3** | パン |
| **PRESETS** | MIXER ではマスター DJ フィルター |

**GLO → SYSTEM → ROUTE** で **1-4** は最初の 4 トラック、**1-6** は 6 トラック、**SEL** は選択トラックを演奏します（有効トラック数に従います）。

T1 と T2 の RX を同じチャンネルにすると 1 台の鍵盤から 2 音色をレイヤーできます。異なるチャンネルなら独立して演奏できます。設定後はプロジェクトを保存してください。

### MIXER とルーティングの詳細

| 操作 | 機能 |
| --- | --- |
| K1 | 選択トラックの MIDI RX チャンネル **1–16** |
| K2 | トラック音量 |
| K3 | パン |
| K4 | MIXER では未割当 |
| PRESETS | MIXER 専用マスター DJ Filter |

有効トラックが 4 つでも、T5/T6 の RX チャンネルを設定できます。有効トラック数は **HOME 長押し → AUDIO → TRACKS** で選びます。

**GLO → SYSTEM → ROUTE** の設定は次の通りです。

- **1-4**：チャンネルが一致するトラック 1–4 に受信 MIDI を送る。
- **1-6**：トラック 1–6 に送る（有効トラック数に従う）。
- **SEL**：現在選択中のトラックだけを演奏する。

たとえば T1 と T2 の RX を **1** にし、ROUTE を **1-6** にすると、チャンネル 1 の鍵盤は両方を同時に鳴らします。それぞれ音色やパンは独立します。

### ZONES の 4 つの範囲

| ノブ | 項目 | 範囲 |
| --- | --- | --- |
| K1 MIN | 受け付ける最低 MIDI ノート | 0–127 |
| K2 MAX | 最高 MIDI ノート | 0–127 |
| K3 V.MIN | 最低ベロシティ | 1–127 |
| K4 V.MAX | 最高ベロシティ | 1–127 |

**両端の数値を含みます。** 同じ RX で T1 を低音域、T2 を高音域にすれば鍵盤スプリット。音域を重ねればレイヤー。ノート範囲を同じにし、T1 をベロシティ **1–80**、T2 を **81–127** にすれば強さで音色が切り替わります。

ゾーンの対象は**外部 MIDI のみ**です。FM1 の内蔵鍵盤は選択したトラックを鳴らします。ノート範囲の判定は**移調前**です。

### TUNING の正確な動作

**GLO → MIX → TUNING** で **K1 TRN = −36〜+36 半音（上下各 3 オクターブ）**、**K2 FINE = −50〜+50 セント**。**K3/K4 は予約済み**です。

TRN はレイヤーを別の高さへ移すのに、FINE は同じ音をわずかにずらして厚くするのに使います。**鳴っているノートの高さは TRN を変更しても変わりません**。新しい Note On から反映され、Note Off とサステインは元の声を正しく終了します。DRUM-X/DRUM-LAB の MIDI マップやドラム音程は TRN/FINE の影響を受けません。

## 3. キーボードゾーンと音程

**GLO → MIX → ZONES** は外部 MIDI の音域とベロシティをフィルターします。

| ノブ | 項目 | 範囲 |
| --- | --- | --- |
| **K1 MIN** | 最低ノート | 0–127 |
| **K2 MAX** | 最高ノート | 0–127 |
| **K3 V.MIN** | 最低ベロシティ | 1–127 |
| **K4 V.MAX** | 最高ベロシティ | 1–127 |

音域を分ければスプリット、重ねればレイヤーになります。ベロシティ範囲を分ければ強さによる音色の切替ができます。ゾーンは外部 MIDI に適用され、内蔵鍵盤は選択トラックを演奏します。

**GLO → MIX → TUNING** の **K1 TRN** は **±36 半音**、**K2 FINE** は **±50 セント**。ドラムの MIDI ノートや音程は変わりません。ゾーン判定は移調前の入力ノートで行います。

### 音源の EDIT ページ一覧

トラックと音色を選んで EDIT を開き、SELECT でページを移動します。各ページの K1〜K4 が表示されたパラメーターに対応します。ENV、LFO、FX、SCL、ARP でも調整できます。

**ATMOS：** BREATH は音量の揺れ、MOTION は動きの速さ、FLOW は音色の変化、SPREAD は 2 オシレーターの分離を調整します。パッド音色から少しずつ増やすと長い音の変化を作れます。

**BRASS：** TYPE は **0 = サックス、約 64 = 中間、127 = トランペット**として連続的に変化します。

| BRASS ページ | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| EDIT 1 | TYPE | PRESS | BUZZ | BREATH |
| EDIT 2 | BODY | FORMNT | GROWL | ATTACK |
| EDIT 3 | FAT | GRIND | METAL | CRUSH |

EDIT 3 は意図的なデチューン、歪み、デジタルな色付けです。自然に近い管楽器の音ならゼロ付近に設定します。

| INDUSTRIAL ページ | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| EDIT 1 | WAVE | FAT | GRIND | METAL |
| EDIT 2 | CRUSH | FEED | CUT | RES |
| EDIT 3 | WAVE2 | MIX | SUB | MODE |

WAVE/MIX はオシレーターの混合、CUT/RES はフィルター、GRIND/METAL/CRUSH は荒い音色の作成に使います。

合計 **8 ボイスを全トラックとドラム音源で共有**します。BRASS にはさらに **1 トラック最大 4 ボイス**の上限があります。音が途切れる場合は同時のレイヤーや和音数を減らしてください。

## 4. 音源とドラム

トラックと音源を選び、**EDIT** を開きます。SELECT で EDIT ページを移動し、K1〜K4 で調整します。

**ATMOS** は変化するパッド音。**BREATH / MOTION / FLOW / SPREAD** で動きとテクスチャーを作ります。**BRASS** は合成管楽器。**TYPE 0** がサックス、**64** が中間、**127** がトランペットです。ほかに PRESS、BUZZ、BREATH、BODY、FORMNT、GROWL、ATTACK、FAT、GRIND、METAL、CRUSH があります。**INDUSTRIAL** は WAVE、FAT、GRIND、METAL、CRUSH、FEED、CUT、RES、WAVE2、MIX、SUB、MODE を持つ強いベース／リード音源です。

**DRUM-X** は独立した 12 音: BD 36、SD 38、CP 39、CH 42、OH 46、TM 45、RM 37、BL 56、B2 41、S2 40、O2 43、T2 44。**DRUM-LAB** は初期設定で MIDI **36–47** の 12 パッドを個別編集できます。

ドラムトラックで **SEQ** を開き、**K1 ノート番号 0–127**、**K2 パン**、**K3 ピッチ ±24 半音**を設定します。**PLAY** は K1 ベロシティカーブ、K2 反応、K3 チョークグループ、K4 重ね合わせ／再スタート。SELECT でパッド、OCT−/OCT+ でバンクを選びます。

音源の発音数は全トラック共有で **8 ボイス**です。BRASS はトラックごとに最大 4 ボイスです。

### DRUM-X の全 MIDI ノート

追加された B2、S2、O2、T2 は元の音と同じ編集機能を持ちますが、**それぞれ独立した設定**を保存します。

| パッド | MIDI | パッド | MIDI |
| --- | --- | --- | --- |
| BD | 36 | RM | 37 |
| SD | 38 | BL | 56 |
| CP | 39 | B2 | 41 |
| CH | 42 | S2 | 40 |
| OH | 46 | O2 | 43 |
| TM | 45 | T2 | 44 |

DRUM-X トラックの EDIT では、**LEVELS 1〜3** が 12 パッドすべての個別音量を調整します。

### DRUM-LAB の編集ページ

| ページ | 設定内容 |
| --- | --- |
| STRIKE | キット全体の PITCH、SWEEP、BODY、SNAP |
| BODY | キット全体の NOISE、TONE、DRIVE、WIRES |
| SOUND 1–4 | 選択パッドの合成パラメーターと種類 |
| LEVELS 1–3 | 12 パッドそれぞれの音量 |

キット全体の倍率は個別パッド設定を書き換えず、全体を比例調整します。**100% は中立**で、小さくするとその成分が弱くなります。

### SEQ：ドラム MIDI マッピング

ドラムトラックで SEQ を押し、ALGORITHM でトラック、SELECT でパッド、OCT−/OCT+ でパッドバンクを選びます。

| ノブ | 機能 |
| --- | --- |
| K1 | パッド MIDI ノート **0–127** |
| K2 | パッドのパン |
| K3 | パッドのピッチ **−24〜+24 半音** |
| K4 | 使用しません |

### PLAY：ドラム演奏設定

| ノブ | 機能 |
| --- | --- |
| K1 | ベロシティカーブ **LIN / SOFT / HARD / FIX** |
| K2 | ベロシティ応答 **0–127** |
| K3 | チョークグループ：なし / **G1–G4** |
| K4 | **OVR**（重ねる）/ **RST**（再スタート） |

同じチョークグループのパッドは互いの発音を止められます。各ヒットでパッドを最初から鳴らすには RST にしてください。

## 5. MIDI CC マクロ

**REC** ではプロジェクトごとに最大 **32** マクロを作れます。**OCT+** → コントローラーから CC を送信 → 対象トラックとパラメーターへ移動 → 対応するノブを回す → REC に戻って調整し、プロジェクトを保存します。

| 操作 | 機能 |
| --- | --- |
| **SELECT** | マクロを選択 |
| **ALGORITHM** | ON/OFF |
| **K1** | RNG（連続範囲）または TGL（切替） |
| **K2 / K3** | 両端値 **0–127** |
| **K4** | 反転 |
| **OCT−** | 削除確認（OCT+ で実行） |

表示 **Y** は有効、**N** は無効、**S** は対象音源がないため一時停止。CC 番号・チャンネル・割当先を変更する場合は削除して作成し直します。

**CC88 / CC89 / CC90** で T1 / T2 / T3 の RX を一時的に変更。値 **0–63 は CH2**、**64–127 は CH1**。**CC85** は弱いランダム化、**CC86** は強いランダム化、**CC87** は保存したメロディー音色を復元します。CC85–87 は MIDI チャンネル **13–15** で、**64–127** が実行、**0–63** が再準備です。

### REC マクロを追加する手順

1. **REC** を開き、**OCT+** で新規マクロを追加します。
2. 外部コントローラーから CC を送ると、番号と MIDI チャンネルが記録されます。
3. 対象トラックと編集可能な音色パラメーターへ移動します。
4. 対応する K ノブを 1 回回して目的地を指定します。
5. REC に戻り範囲を設定してプロジェクトを保存します。

| REC 操作 | 機能 |
| --- | --- |
| SELECT | マクロ選択（1 ページ 4 行） |
| ALGORITHM | 有効 / 無効 |
| K1 | **RNG**（連続範囲）または **TGL**（2 値切替） |
| K2/K3 | 最小 / 最大または A/B：**0–127** |
| K4 | 入力方向を反転 |
| OCT− | 削除確認、**OCT+** で確定 / OCT− で中止 |

**Y** は有効、**N** は無効、**S** は対象エンジンがないため一時停止。エンジンを戻すと有効に復帰します。**CC 番号、チャンネル、対象パラメーターは編集できません**。変更するには削除して作り直してください。複数のマクロで同じ CC とチャンネルを使用し、異なる音色パラメーターを同時操作できます。

### MIDI Learn と REC は別の機能

全体設定の **MIDI Learn** には REC とは別に **32 個の学習先**があります。**HOME 長押し → MIDI → LEARN** を開き、パラメーターを選んでコントローラーを操作します。これはプロジェクト専用 REC マクロとは別に管理されます。

### 専用 CC ショートカット

| CC | 操作 |
| --- | --- |
| CC88 / CC89 / CC90 | T1 / T2 / T3 の RX を一時的に変更 |
| CC85 | メロディー音色を弱くランダム化 |
| CC86 | 強くランダム化 |
| CC87 | 最後に保存した音色パラメーターを復元 |

**CC88–90**：どの MIDI チャンネルからでも、値 **0–63 で RX 2**、**64–127 で RX 1**。保存済み RX は上書きしません。プロジェクトを再読み込みすると保存した RX に戻ります。

**CC85–87**：T1 は **チャンネル 13**、T2 は **14**、T3 は **15**。値 **64–127** で実行、**0–63** で再準備。ドラムには適用されません。CC87 は、エンジンが切り替わっていなければ、すでに鳴っているノートを切らずにパラメーターを戻します。

## 6. EQ・プロジェクト・ライブ操作

**GLO → MIX → EQ** は共通 3 バンド EQ。**LOW 50 Hz / MID 700 Hz / HIGH 10 kHz**、それぞれ **±15 dB**。各トラック専用ではなくエフェクト前に作用します。

**SAVE** で音色やプロジェクトを保存します。プロジェクトにはトラック、RX、ゾーン、チューニング、マクロ、エフェクトなどが記録されます。**SAVE → LIBRARY → TOOLS**: **K1 INIT SOUND**、**K2 CLEAR SLOT**（確認後に削除）、**K3 NEW PROJECT**、**K4 CPU TEST**。

**Live Recall** は REC 長押しで切り替え、**FX / SEL / ENV / LFO** の短押しでプロジェクト **1 / 2 / 3 / 4** を呼び出します。もう一度 REC 長押しで終了。

**PANIC** は **GLO を押したまま OCT−**。発音中の音・エフェクト・サステイン状態を停止します。プロジェクトは削除しません。

ファームウェアを変更する前に、[MASHINA エディター](../webapp/editor/)でプロジェクト、ユーザープリセット、設定の完全バックアップを保存してください。[インストーラー](../webapp/installer/)は別ページです。

### 共有 3 バンド EQ

**GLO → MIX → EQ** を開きます。

| バンド | 周波数 | 範囲 |
| --- | --- | --- |
| LOW | **50 Hz** | −15〜+15 dB |
| MID | **700 Hz** | −15〜+15 dB |
| HIGH | **10 kHz** | −15〜+15 dB |
| ON | EQ の有効 / バイパス | — |

EQ は **エフェクト前に置かれた全体共通の 1 つの EQ** で、トラックごとではありません。FX とセンドを併用し、保存する場合はプロジェクトを保存します。

### SAVE とライブラリー

| SAVE → LIBRARY → TOOLS | 機能 |
| --- | --- |
| K1 | **INIT SOUND**：音色を初期化 |
| K2 | **CLEAR SLOT**：確認後、選択したプロジェクトスロットを完全に削除 |
| K3 | **NEW PROJECT**：新規プロジェクト |
| K4 | **CPU TEST**：CPU 負荷テスト |

プロジェクトは RX、ゾーン、調律、マクロ、音色、関連するエフェクトを記録します。保存しないで別のプロジェクトを読み込むと変更が失われます。

### Live Recall の詳しい操作

**REC を長押し**して Live Recall を有効にし、**FX / SEL / ENV / LFO** を短く押してスロット **1 / 2 / 3 / 4** を呼び出します。再度 REC を長押しで終了します。プロジェクト変更時に前のノートは停止しますが、ディレイやリバーブの余韻は自然に残ることがあります。

### PANIC とバックアップ

**GLO を押しながら OCT−** で発音、エフェクト、押したままのノートとサステインの状態を即座に停止します。GLO を押している間 PANIC MODE と表示されます。**プロジェクトは削除しません。**

更新または古いバージョンへの変更前に、**プロジェクト、ユーザープリセット、設定の完全バックアップ**を保存してください。単独の音色プリセットの書き出しはデバイス全体のバックアップではありません。[MASHINA エディター](https://mishamashinamm.github.io/mashina-fm1-fw/webapp/editor/)で保存し、[インストーラー](https://mishamashinamm.github.io/mashina-fm1-fw/webapp/installer/)から導入します。

## 7. ライブ設定の例

**レイヤー:** T1/T2 を RX 1 にし、同じ ZONES 音域に異なる音源を割り当てます。

**スプリット:** T1/T2 を RX 1 にし、MIN/MAX で重ならない音域を設定します。

**ベロシティで切替:** 同じ RX と音域、T1 は 1–80、T2 は 81–127。

**1 つのペダルで複数の音色:** REC で同じ CC・チャンネルのマクロを複数作り、別々のパラメーターを割り当てます。

**外部ドラムパッド:** MIXER で RX、SEQ でノート、PLAY でベロシティ／チョーク／リトリガーを設定します。
