# MASHINA — руководство пользователя FM1

MASHINA превращает M-VAVE FM1 в шестидорожечный звуковой модуль для внешних MIDI-клавиатур, пэдов и контроллеров. Здесь описаны настройки и приёмы для живого исполнения.

## 1. Органы управления и навигация

**HOME** возвращает на основной экран; удерживание открывает меню настроек. **GLO** — микшер и общие настройки, **EDIT** — параметры звука, **ENV / LFO / FX** — огибающие, модуляция и эффекты. **SAVE** — звуки и проекты. **SEQ** — MIDI-карта барабанов, **PLAY** — настройки их исполнения, **REC** — MIDI-макросы. Песенный секвенсор отключён.

Поворачивайте **SELECT** для смены страниц. **ALGORITHM** обычно выбирает дорожку. **K1–K4** меняют показанные параметры. **OCT−/OCT+** меняют октаву встроенной клавиатуры.

Удерживайте HOME для меню: **SCREEN / AUDIO / MIDI / USB / CONTROLS / SYSTEM**. В **AUDIO → TRACKS** активируйте четыре или шесть дорожек. **MIDI → LEARN** — обучение контроллерам; **LEARN CLEAR** удаляет назначения.

## 2. Внешний MIDI и микшер

Подключите совместимый USB- или TRS-MIDI-контроллер. Откройте **GLO → MIX → MIXER**, выберите T1–T6 с помощью ALGORITHM.

| Управление | Функция |
| --- | --- |
| **K1** | Входной MIDI-канал RX **1–16** |
| **K2** | Громкость дорожки |
| **K3** | Панорама |
| **PRESETS** | Мастер DJ Filter (только MIXER) |

В **GLO → SYSTEM → ROUTE** режим **1-4** использует первые четыре дорожки, **1-6** — все шесть, **SEL** — только выбранную (с учётом числа активных дорожек).

Назначьте T1 и T2 **один RX-канал**, чтобы клавиатура играла сразу двумя тембрами; разные каналы позволят управлять дорожками независимо. Сохраните проект.

## 3. Зоны клавиатуры и строй

В **GLO → MIX → ZONES** задаются допустимые внешние MIDI-ноты и скорость нажатия:

| Регулятор | Параметр | Диапазон |
| --- | --- | --- |
| **K1 MIN** | Нижняя нота | 0–127 |
| **K2 MAX** | Верхняя нота | 0–127 |
| **K3 V.MIN** | Минимальная velocity | 1–127 |
| **K4 V.MAX** | Максимальная velocity | 1–127 |

Неперекрывающиеся диапазоны создают **разделение клавиатуры**, перекрывающиеся — **слои**. Зоны velocity позволяют выбирать тембр силой нажатия. Они действуют на внешний MIDI, а встроенная клавиатура играет выбранную дорожку.

В **GLO → MIX → TUNING** **K1 TRN** транспонирует на **−36…+36 полутонов**, **K2 FINE** подстраивает на **−50…+50 центов**. Для барабанных движков эти параметры не меняют карту MIDI-нот; зоны проверяются до транспонирования.

## 4. Синтезаторы и барабаны

Выберите дорожку и движок, затем откройте **EDIT**. **SELECT** листает страницы, **K1–K4** меняют параметры.

**ATMOS** — плавно меняющиеся гармонические пэды; **BREATH / MOTION / FLOW / SPREAD** управляют движением звука. **BRASS** — синтетические духовые; **TYPE 0** соответствует саксофону, **64** промежуточному тембру, **127** трубе. Другие параметры: PRESS, BUZZ, BREATH, BODY, FORMNT, GROWL, ATTACK, FAT, GRIND, METAL, CRUSH. **INDUSTRIAL** — насыщенные басы и лиды, с WAVE, FAT, GRIND, METAL, CRUSH, FEED, CUT, RES, WAVE2, MIX, SUB и MODE.

**DRUM-X** содержит двенадцать звуков: BD 36, SD 38, CP 39, CH 42, OH 46, TM 45, RM 37, BL 56, B2 41, S2 40, O2 43, T2 44. **DRUM-LAB** — двенадцать синтезируемых пэдов, по умолчанию MIDI **36–47**.

Для барабанной дорожки **SEQ**: **K1** MIDI-нота **0–127**, **K2** панорама, **K3** высота **±24 полутона**. **PLAY**: **K1** кривая velocity, **K2** сила реакции, **K3** choke-группа, **K4** наложение или перезапуск. SELECT выбирает пэд, OCT−/OCT+ переключают банк.

**Восемь голосов общие для всех дорожек**. BRASS ограничен четырьмя голосами на дорожку. Сложные слои могут исчерпать полифонию.

## 5. MIDI CC-макросы

Откройте **REC**. Проект может хранить **32 макроса**. Для нового: нажмите **OCT+**, отправьте CC с контроллера, перейдите к нужному звуковому параметру и поверните его регулятор. Вернитесь в REC и сохраните проект.

| Управление | Действие |
| --- | --- |
| **SELECT** | Выбрать макрос |
| **ALGORITHM** | Вкл./выкл. |
| **K1** | RNG (непрерывный диапазон) / TGL (переключение) |
| **K2 / K3** | Конечные значения **0–127** |
| **K4** | Обратное направление |
| **OCT−** | Удалить (подтвердить OCT+) |

**Y** — активен, **N** — выключен, **S** — временно приостановлен из-за отсутствующего движка. Номер CC, канал и назначение нельзя изменить: удалите и создайте заново.

**CC88/89/90** временно переключают RX T1/T2/T3: значение **0–63 = канал 2**, **64–127 = канал 1**. **CC85** слегка рандомизирует мелодический звук, **CC86** сильнее, **CC87** восстанавливает сохранённые параметры. Для CC85–87 используйте каналы **13–15**, значение **64–127** запускает, **0–63** снова подготавливает.

## 6. EQ, проекты и живые функции

**GLO → MIX → EQ** — общий трёхполосный эквалайзер перед эффектами: **LOW 50 Гц**, **MID 700 Гц**, **HIGH 10 кГц**, каждый **±15 дБ**. Это не EQ отдельных дорожек.

В **SAVE** сохраняются звуки и проекты: дорожки, MIDI, зоны, строй, макросы, эффекты. **SAVE → LIBRARY → TOOLS**: **K1 INIT SOUND**, **K2 CLEAR SLOT** (удаление после подтверждения), **K3 NEW PROJECT**, **K4 CPU TEST**.

**Live Recall:** удерживайте REC, затем нажимайте **FX / SEL / ENV / LFO** для проектов **1 / 2 / 3 / 4**. Снова удерживайте REC для выхода.

**PANIC:** удерживайте **GLO** и нажмите **OCT−**. Звучащие голоса, эффекты и sustain сбрасываются без удаления проекта.

Перед сменой прошивки сохраните полную копию проектов, пресетов и настроек через [MASHINA web editor](../webapp/editor/). Для установки используйте [инсталлятор](../webapp/installer/).

## 7. Примеры для сцены

**Два тембра слоями:** T1 и T2 на RX 1, одинаковые ZONES, разные синтезаторы и панорама.

**Разделение клавиатуры:** один RX-канал, неперекрывающиеся MIN/MAX.

**Смена по velocity:** T1 1–80, T2 81–127, один канал и диапазон нот.

**Один регулятор — много параметров:** создайте несколько REC-макросов с тем же CC и каналом, но разными целями.

**Внешние барабанные пэды:** RX на MIXER, ноты на SEQ, velocity и choke на PLAY.
