# MASHINA — руководство пользователя FM1

MASHINA превращает M-VAVE FM1 в шестидорожечный звуковой модуль для внешних MIDI-клавиатур, пэдов и контроллеров. Здесь описаны настройки и приёмы для живого исполнения.

## 1. Органы управления и навигация

**HOME** возвращает на основной экран; удерживание открывает меню настроек. **GLO** — микшер и общие настройки, **EDIT** — параметры звука, **ENV / LFO / FX** — огибающие, модуляция и эффекты. **SAVE** — звуки и проекты. **SEQ** — MIDI-карта барабанов, **PLAY** — настройки их исполнения, **REC** — MIDI-макросы. Песенный секвенсор отключён.

Поворачивайте **SELECT** для смены страниц. **ALGORITHM** обычно выбирает дорожку. **K1–K4** меняют показанные параметры. **OCT−/OCT+** меняют октаву встроенной клавиатуры.

Удерживайте HOME для меню: **SCREEN / AUDIO / MIDI / USB / CONTROLS / SYSTEM**. В **AUDIO → TRACKS** активируйте четыре или шесть дорожек. **MIDI → LEARN** — обучение контроллерам; **LEARN CLEAR** удаляет назначения.

### Полный список органов управления

| Кнопка | Назначение |
| --- | --- |
| HOME | Возврат на главный экран; удерживание открывает настройки. |
| GLO | Микшер, MIDI-зоны, строй, посылы, общий EQ, системные настройки. |
| EDIT | Редактирование звукового движка выбранной дорожки. |
| ENV | Огибающие и цели модуляции. |
| LFO | LFO, модуляция и движение тембра. |
| FX | Эффекты дорожек и общие эффектные шины. |
| SCL / ARP | Лады, аккорды и арпеджиатор. |
| SAVE | Звуки, пресеты, проекты и библиотека. |
| SEQ | Карта MIDI-нот, панорамы и высоты барабанов; не песенный секвенсор. |
| PLAY | Барабанная velocity, заглушение (choke), повторный запуск. |
| REC | До 32 MIDI CC-макросов на проект. |
| ALGORITHM | Обычно выбирает дорожку, кроме страниц с особой функцией. |
| SELECT | Перемещает между страницами, на барабанных — выбирает пэд. |
| K1–K4 | Меняют четыре соответствующих параметра на экране. |
| PRESETS | Выбирает звуки, за исключением страниц с иной функцией. |
| OCT− / OCT+ | Меняют октаву встроенной клавиатуры; вместе сбрасывают смещение. |

Обычно один раз нажмите кнопку раздела, поворачивайте SELECT для смены страницы и нужный регулятор K для изменения значения. Изменения действуют сразу, но их нужно **сохранить в проекте**.

### Страницы меню настроек

Удерживайте HOME и поворачивайте SELECT.

| Страница | Параметры |
| --- | --- |
| SCREEN | Осциллограмма, сон экрана, яркость LED, подсветка лада |
| AUDIO | EQ динамика, активные дорожки 4/6, нагрузка, BPM LOCK |
| MIDI | Выход MIDI, MIDI Learn, удаление изученных команд |
| USB | USB-аудио и уровень |
| CONTROLS | Время удерживания, ускорение регуляторов, FX latch, калибровка |
| SYSTEM | Восстановление последнего состояния, ядра и частота CPU, ABOUT |

Показанный регулятор K изменяет значение, HOME выходит. **LEARN CLEAR** удаляет назначения — подтверждайте только когда хотите их стереть.

## 2. Внешний MIDI и микшер

Подключите совместимый USB- или TRS-MIDI-контроллер. Откройте **GLO → MIX → MIXER**, выберите T1–T6 с помощью ALGORITHM.

| Управление | Функция |
| --- | --- |
| **K1** | Входной MIDI-канал RX **1–16** |
| **K2** | Громкость дорожки |
| **K3** | Панорама |
| **PRESETS** | Мастер DJ Filter (только MIXER) |

В **GLO → SYSTEM → ROUTE** режим **1-4** использует первые четыре дорожки, **1-6** — все шесть, **SEL** — только выбранную (с учётом числа активных дорожек).

Назначьте T1 и T2 **один RX-канал**, чтобы клавиатура играла сразу двумя тембрами; разные каналы позволят управлять дорожками независимо. Сохраните проект.

### MIXER: все регуляторы

| Управление | Функция |
| --- | --- |
| K1 | MIDI-канал RX выбранной дорожки, **1–16** |
| K2 | Громкость дорожки |
| K3 | Панорама |
| K4 | На MIXER не назначен |
| PRESETS | Общий DJ Filter, только на MIXER |

Каналы T5/T6 можно настраивать даже при четырёх активных дорожках. Их количество задаётся через **HOME (удерживать) → AUDIO → TRACKS**.

### Режимы маршрутизации

Откройте **GLO → SYSTEM → ROUTE**.

- **1-4** — входные MIDI-сообщения направляются на дорожки 1–4 с совпадающим RX-каналом.
- **1-6** — то же для дорожек 1–6 с учётом числа активных.
- **SEL** — все входящие ноты идут на выбранную дорожку.

Пример: T1 и T2 имеют RX 1, ROUTE = 1-6, клавиатура посылает на канале 1. Играют обе дорожки, с независимыми звуками и панорамой.

### Диапазоны нот и скорости нажатия

| Регулятор | Параметр | Диапазон |
| --- | --- | --- |
| K1 MIN | Самая низкая допустимая MIDI-нота | 0–127 |
| K2 MAX | Самая высокая нота | 0–127 |
| K3 V.MIN | Минимальная velocity | 1–127 |
| K4 V.MAX | Максимальная velocity | 1–127 |

**Границы включаются.** Для разделения клавиатуры задайте T1 низкий диапазон, T2 высокий, но одинаковый RX. Перекрывающиеся диапазоны дают два слоя. Если диапазон нот общий, задайте T1 velocity **1–80**, T2 **81–127** — тембр выбирается силой нажатия.

Зоны фильтруют **только внешний MIDI**. Встроенная клавиатура играет выбранную дорожку. Проверка зоны происходит **до транспонирования**.

### TRN/FINE при удержании нот

В **GLO → MIX → TUNING**: **K1 TRN = −36…+36 полутонов** (три октавы в обе стороны), **K2 FINE = −50…+50 центов**; **K3 DLY** задерживает любую дорожку на 0–50 мс, включая мелодические движки. На барабанах он суммируется с K4 пэда; K4 на странице TUNING остаётся резервным. Для мелодических движков Note On и Note Off сдвигаются на одинаковое время, сохраняя длительность ноты. MIDI-логика педали sustain не меняется. TRN перемещает слой вверх/вниз, FINE слегка расстраивает унисон для более плотного звука.

Если нота уже звучит, **изменение TRN не меняет её текущую высоту**; новые ноты играют с новой настройкой. Note Off и sustain продолжают правильно завершать ноты. DRUM-X/DRUM-LAB сохраняют собственные ноты и высоту независимо от TRN/FINE.

## 3. Зоны клавиатуры и строй

В **GLO → MIX → ZONES** задаются допустимые внешние MIDI-ноты и скорость нажатия:

| Регулятор | Параметр | Диапазон |
| --- | --- | --- |
| **K1 MIN** | Нижняя нота | 0–127 |
| **K2 MAX** | Верхняя нота | 0–127 |
| **K3 V.MIN** | Минимальная velocity | 1–127 |
| **K4 V.MAX** | Максимальная velocity | 1–127 |

Неперекрывающиеся диапазоны создают **разделение клавиатуры**, перекрывающиеся — **слои**. Зоны velocity позволяют выбирать тембр силой нажатия. Они действуют на внешний MIDI, а встроенная клавиатура играет выбранную дорожку.

В **GLO → MIX → TUNING** **K1 TRN** транспонирует на **−36…+36 полутонов**, **K2 FINE** подстраивает на **−50…+50 центов**. Для барабанных движков эти параметры не меняют карту MIDI-нот; зоны проверяются до транспонирования.

### Редактирование ATMOS, BRASS и INDUSTRIAL

Выберите дорожку, движок/пресет, откройте EDIT и поворачивайте SELECT для перехода по страницам. K1–K4 изменяют соответствующие параметры. Дополнительно доступны ENV, LFO, FX, SCL и ARP.

**ATMOS** создаёт медленно меняющиеся гармонические пэды. **BREATH** управляет движением громкости, **MOTION** скоростью, **FLOW** изменением тембра, **SPREAD** раздвижением осцилляторов. Начните с пресета пэда и постепенно добавляйте движение.

**BRASS:** **TYPE 0** соответствует саксофону, около **64** — промежуточным тембрам, **127** — трубе.

| Страница BRASS | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| EDIT 1 | TYPE | PRESS | BUZZ | BREATH |
| EDIT 2 | BODY | FORMNT | GROWL | ATTACK |
| EDIT 3 | FAT | GRIND | METAL | CRUSH |

EDIT 3 добавляет расстройку, искажения и цифровую окраску. Для более чистого духового тембра используйте низкие значения.

| Страница INDUSTRIAL | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| EDIT 1 | WAVE | FAT | GRIND | METAL |
| EDIT 2 | CRUSH | FEED | CUT | RES |
| EDIT 3 | WAVE2 | MIX | SUB | MODE |

WAVE/MIX смешивают генераторы, CUT/RES управляют фильтром, GRIND/METAL/CRUSH усиливают жёсткость звучания.

**Восемь голосов синтеза общие для всех дорожек и барабанных движков**, а BRASS имеет ограничение **четыре голоса на дорожку**. Если ноты обрываются, уменьшите число одновременных слоёв.

### Заводские звуки в v0.12

Обновлённый заводской банк включает 20 звуков ANALOG, 12 INDUSTRIAL, 5 BRASS и 8 ATMOS, а также новые банки PHASE, WHEEL, NOISE, FM6, VOICE и LOFI. Многие пресеты названы в честь философов и мыслителей разных исторических эпох. DRUM-X: BUTTLER-1…9; DRUM-LAB: ZIZEK-1…3; DRUM-AC: KRIPKE-1…3; DRUM-IND: BADIOU-1…3.


## 4. Синтезаторы и барабаны

Выберите дорожку и движок, затем откройте **EDIT**. **SELECT** листает страницы, **K1–K4** меняют параметры.

### Звуковые движки, сохранённые из JIANT

Эти восемь движков доступны вместе с новыми. Начните с заводского пресета, затем измените звучание через EDIT.

| Движок | Звук и основные настройки |
| --- | --- |
| **ANALOG** | Субтрактивные басы, лиды, щипковые звуки и пэды; осцилляторы, расстройка, фильтр и перегруз. |
| **PHASE** | Фазовое искажение для синтетических духовых, колоколов, клавишных и басов; DCW и ENV меняют форму волны. |
| **LOFI** | Чиптюн, волновые таблицы, bytebeat и игровые текстуры; CHIP, WAVE, DUTY, SWEEP и цифровое огрубление. |
| **VOICE** | Поющие гласные, хоры, роботизированные и речевые тембры; VOWEL, VOWEL2 и TALK меняют форманты. |
| **WHEEL** | Орган с тоновыми колёсами, регистрами, перкуссией, щелчком клавиш, перегрузом и роторным эффектом. |
| **NOISE** | Ветер, дождь, потрескивания, металлические и ретро-шумы; MODE, COLOR, FREQ и PEAK. |
| **FM6** | Шестиоператорный FM: электропиано, колокола, басы и цифровые тембры; алгоритмы и огибающие операторов. |

**DRUM-X** развивает оригинальный барабанный движок и подробно описан ниже вместе с остальными комплектами.

### Дополнительные мелодические движки MASHINA

**ATMOS — развивающиеся пэды и текстуры.** Для начала используйте **KANT**, **BURKE** или **JEFFERSON**. **WAVE** выбирает форму волны; **MORPH, DENSITY, DRIFT** создают движение слоёв; **CUT/RES** управляют фильтром, **TEXTURE/SHIMMER** добавляют окраску. **BREATH** меняет громкость, **MOTION** скорость, **FLOW** тембр со временем, **SPREAD** разделяет осцилляторы. Для многослойных аккордов полезны умеренные значения.

**BRASS — электронные саксофоны, духовые и трубы.** Это синтетический инструмент, а не точная акустическая модель. **TYPE 0** ближе к саксофону, **127** к трубе, между ними гибридные варианты. **PRESS** задаёт напор, **BUZZ** шершавость, **BREATH** воздушность, **BODY/FORMNT** резонансы, **GROWL** рычание и **ATTACK** начало ноты. Третья страница — **FAT, GRIND, METAL, CRUSH** — даёт плотные и искажённые звуки. Начните с **HUME**, **DIDEROT**, **HOLBACH**.

**INDUSTRIAL — агрессивные мелодические басы и лиды.** В отличие от DRUM-IND, этот движок следует сыгранным нотам. **WAVE** выбирает осциллятор; **FAT** утолщает звук; **GRIND/METAL/CRUSH/FEED** добавляют грязь; **CUT/RES** управляют фильтром. **WAVE2, MIX, SUB, MODE** на третьей странице настраивают второй осциллятор и низкие частоты. Попробуйте **PASCAL**, **NEWTON**, **CAVENDISH**, **LOCKE**.

**DRUM-X** содержит двенадцать звуков: BD 36, SD 38, CP 39, CH 42, OH 46, TM 45, RM 37, BL 47, B2 41, S2 40, O2 43, T2 44. **DRUM-LAB** — двенадцать синтезируемых пэдов, по умолчанию MIDI **36–47**.

Для барабанной дорожки **SEQ**: **K1** MIDI-нота **0–127**, **K2** панорама, **K3** высота **±24 полутона**. **PLAY**: **K1** кривая velocity, **K2** сила реакции, **K3** choke-группа, **K4** наложение или перезапуск. SELECT выбирает пэд, OCT−/OCT+ переключают банк.

**Восемь голосов общие для всех дорожек**. BRASS ограничен четырьмя голосами на дорожку. Сложные слои могут исчерпать полифонию.

### Полная карта DRUM-X

Дополнительные B2, S2, O2 и T2 — отдельные экземпляры соответствующих звуков с независимыми настройками и теми же параметрами синтеза.

| Пэд | MIDI-нота | Пэд | MIDI-нота |
| --- | --- | --- | --- |
| BD | 36 | RM | 37 |
| SD | 38 | BL | 47 |
| CP | 39 | B2 | 41 |
| CH | 42 | S2 | 40 |
| OH | 46 | O2 | 43 |
| TM | 45 | T2 | 44 |

В EDIT движка DRUM-X используйте страницы **LEVELS 1–3** для уровней всех двенадцати пэдов.

### DRUM-LAB: страницы редактирования

| Страница | Настройки |
| --- | --- |
| STRIKE | Общие PITCH, SWEEP, BODY, SNAP |
| BODY | Общие NOISE, TONE, DRIVE, WIRES |
| SOUND 1–4 | Тип и параметры синтеза выбранного пэда |
| LEVELS 1–3 | Отдельные уровни всех 12 пэдов |

Общие множители меняют масштаб индивидуальных настроек, не заменяя их. При **100%** они нейтральны; снижение ослабляет соответствующую составляющую звука.

### DRUM-AC: акустически ориентированный набор из 12 пэдов

**DRUM-AC** — третий самостоятельный барабанный движок. Все звуки **синтезируются без сэмплов**: шумовые удары, резонанс мембран томов и затухающие металлические полосы для тарелок. Пресеты: **KRIPKE-1**, **KRIPKE-2**, **KRIPKE-3**. DRUM-X и DRUM-LAB не изменены.

**Хроматическая раскладка повторяется в каждой октаве.** Номера MIDI ниже приведены для октавы **36–47**; те же ноты в других октавах запускают те же пэды:

| Клавиша (MIDI) | Звук | Клавиша (MIDI) | Звук |
| --- | --- | --- | --- |
| C (36) | Бочка | F♯ (42) | Закрытый хай-хэт |
| C♯ (37) | Крэш | G (43) | Низкий том |
| D (38) | Малый барабан | G♯ (44) | Райд splash |
| D♯ (39) | Хлопок | A (45) | Средний том |
| E (40) | Колокол райда | A♯ (46) | Открытый хай-хэт |
| F (41) | Напольный том | B (47) | Высокий том |

Закрытый хай-хэт глушит открытый в любой октаве, не обрывая крэш или райд. 

**Страницы EDIT для DRUM-AC:**

| Страница | Управление |
| --- | --- |
| **Первые две общие страницы EDIT** | Восемь независимых регуляторов всего набора: **TONE, DAMP, BODY, ATTACK, BRIGHT, TEXTURE, RING, LEVEL**. Диапазон **0–200%**, **100% — нейтральное значение**. Отдельные настройки пэдов не перезаписываются. |
| **SOUND 1–3** | **K1** выбирает один из 12 пэдов, **K2–K4** настраивают его восемь параметров **0–127** на трёх страницах: TUNE, DAMP, BODY, HIT, параметр удара, BRIGHT, параметр характера и RING/DECAY/TAIL. |
| **LEVELS 1–3** | Независимая громкость **0–127** для каждого из двенадцати пэдов. |

Имена параметров пэда зависят от инструмента: **BEATER / TEXTURE** у бочки, **WIRES / TEXTURE** у малого барабана, **SPLASH / METAL** у крэша, **CHICK / DECAY** у хай-хэта, **STICK / SHELL** у томов, **SNAP / TEXTURE / TAIL** у хлопка, **STRIKE** у колокола райда и **SPLASH** у ride splash. В отличие от общих восьми регуляторов, отдельные параметры не обязаны иметь одинаковое действие на разных звуках.

**Настройка томов:** каждый том независим. При **TUNE = 0** тональная резонансная составляющая мембраны отключена — остаётся непериодический удар. При **1–127** добавляется отчётливо слышимый резонанс от низкой к высокой ноте; шумовая часть удара не меняется. **SPLASH** регулирует шумовую атаку и металлический шлейф крэша и ride splash.

Настройки пэдов, их уровни и восемь общих регуляторов сохраняются в проекте. DRUM-AC использует общие **восемь голосов синтеза**, а не двенадцать отдельных голосов сэмплера. Звуки тарелок — синтетические приближения, а не записи настоящих тарелок.


### DRUM-IND: индустриальная перкуссия без музыкального строя

**DRUM-IND** — четвёртый отдельный движок с 12 синтезируемыми звуками, **без сэмплов**. Он отличается от мелодического синтезатора **INDUSTRIAL**: используется шумовое возбуждение, движущиеся резонансные фильтры, удары и нерегулярные механические импульсы вместо настроенных по нотам осцилляторов. Звуки можно накладывать на другие ударные наборы через общий MIDI-канал.

**Фиксированная хроматическая раскладка повторяется в каждой октаве.** MIDI-ноты 36–47 приведены как пример.

| Клавиша (MIDI) | Звук / характер | Клавиша (MIDI) | Звук / характер |
| --- | --- | --- | --- |
| C (36) | **CLANG** — металлический удар | F♯ (42) | **BUZZ** — электрическое жужжание |
| C♯ (37) | **ANVIL** — сильный удар молота | G (43) | **LIGHTNING** — разряд и треск |
| D (38) | **METAL** — резонанс листового металла | G♯ (44) | **ENGINE** — неровная работа механизма |
| D♯ (39) | **SCRAPE** — скрежет металла | A (45) | **WHOOSH** — поток воздуха |
| E (40) | **WHISTLE** — воздушный свист | A♯ (46) | **MOTOR** — вращающийся мотор |
| F (41) | **SCREECH** — резкий визг | B (47) | **EXPLOSION** — взрыв и шумовой хвост |

**Страницы EDIT:** первые две управляют всем набором: **TONE, DAMP, BODY, ATTACK, BRIGHT, TEXTURE, RING, LEVEL** (каждый **0–200%**, **100% нейтрально**). ATTACK заметно изменяет примерно первые 80 мс удара; BRIGHT регулирует высокие частоты после ограничения звука. На страницах **SOUND 1–3** ручка **K1** выбирает пэд, **K2–K4** меняют восемь индивидуальных параметров (**0–127**): **GRAIN, DECAY, WEIGHT, STRIKE, MOTION, AIR, CRUNCH, TAIL**. **LEVELS 1–3** задают двенадцать независимых громкостей (**0–127**). Эффект параметра может различаться по звукам.

Пресеты: **BADIOU-1**, **BADIOU-2**, **BADIOU-3**. Параметры пэдов, уровни и общие настройки сохраняются в проекте. Всего доступно **восемь общих голосов** синтеза. 


### SEQ: назначение нот барабанов

На барабанной дорожке нажмите SEQ. ALGORITHM выбирает дорожку, SELECT — пэд, OCT−/OCT+ — банк.

| Регулятор | Действие |
| --- | --- |
| K1 | MIDI-нота пэда **0–127** |
| K2 | Панорама пэда |
| K3 | Высота пэда **−24…+24 полутона** |
| K4 | DLY: задержка пэда 0–50 мс |

**DEFAULT / CUSTOM — все четыре барабанных движка.** В **DEFAULT** DRUM-X, DRUM-LAB, DRUM-AC и DRUM-IND повторяют те же 12 пэдов во всех октавах: C на MIDI 36, 48, 60 и 72 запускает один звук без изменения высоты.

Изменение любой ноты пэда с помощью **K1** включает **CUSTOM только для выбранной дорожки**. Все 12 пэдов теперь реагируют только на точно назначенные MIDI-ноты (0–127). Неизменённые пэды остаются на заводских нотах 36–47, но больше не повторяются в других октавах. Несколько пэдов могут звучать вместе на одной ноте. Индикатор **DEFAULT / CUSTOM** находится справа вверху.

Для возврата в DEFAULT удерживайте **физическую кнопку SEL** (не поворотный регулятор SELECT) около **0,7 секунды**: появится **RESET MIDI MAP?**. **OCT− отменяет**, **OCT+ сбрасывает только выбранную дорожку** и восстанавливает повторение по октавам, не затрагивая параметры звука, панораму, высоту и другие дорожки. Возврат номеров нот вручную не выключает CUSTOM: нужен RESET. Карты сохраняются с проектом. Во всех четырёх барабанных движках **K2 PAN** задаёт положение пэда в стерео (L64–C–R64), а **K3 PITCH** сдвигает высоту на −24…+24 полутона. Для нетональных звуков DRUM-AC и DRUM-IND изменяются резонансные частоты и спектральная окраска, а не появляется мелодический тон.

**K4 DLY** добавляет задержку 0–50 мс для выбранного пэда. **GLO → MIX → TUNING → K3 DLY** добавляет ещё 0–50 мс для всей дорожки: значения суммируются (например, 12 + 7 = 19 мс). По умолчанию оба равны нулю. Настройки сохраняются в проекте и действуют во всех четырёх барабанных движках. Случайная вариация времени пока не включена.


### PLAY: параметры исполнения

| Регулятор | Действие |
| --- | --- |
| K1 | Кривая velocity **LIN / SOFT / HARD / FIX** |
| K2 | Реакция velocity **0–127** |
| K3 | Группа choke: нет / **G1–G4** |
| K4 | **OVR** (наложение) / **RST** (перезапуск) |

Пэды в одной choke-группе могут заглушать друг друга. RST заставляет каждый новый удар запускать звук сначала, а не накладывать его на предыдущий.

## 5. MIDI CC-макросы

Откройте **REC**. Проект может хранить **32 макроса**. Для нового: нажмите **OCT+**, отправьте CC с контроллера, перейдите к нужному звуковому параметру и поверните его регулятор. Вернитесь в REC и сохраните проект.

| Управление | Действие |
| --- | --- |
| **SELECT** | Выбрать макрос |
| **ALGORITHM** | Вкл./выкл. |
| **K1** | RNG (непрерывный диапазон) / TGL (переключение) |
| **K2 / K3** | Конечные значения **0–127** |
| **K4** | Обратное направление |
| **OCT−** | Удалить (подтвердить OCT+) |

**Y** — активен, **N** — выключен, **S** — временно приостановлен из-за отсутствующего движка. Номер CC, канал и назначение нельзя изменить: удалите и создайте заново.

**CC88/89/90** временно переключают RX T1/T2/T3: значение **0–63 = канал 2**, **64–127 = канал 1**. **CC85** слегка рандомизирует мелодический звук, **CC86** сильнее, **CC87** восстанавливает текущий звук до рандомизации. Для CC85–87 используйте каналы **13–15** (T1/T2/T3), значение **64–127** запускает, **0–63** снова подготавливает. Команды действуют на текущий загруженный звук: заводской, пользовательский пресет или звук из проекта; предварительно сохранять его не нужно. CC87 возвращает параметры до рандомизации, не прерывая уже звучащие ноты. Выбор нового пресета задаёт новую исходную точку. Поддерживаются все мелодические движки, включая ATMOS, BRASS, INDUSTRIAL и FM6, но не DRUM-X, DRUM-LAB, DRUM-AC и DRUM-IND. Выбор волны и FM-патча защищён от изменений.

### Создание REC-макроса: каждый шаг

1. Откройте **REC** и нажмите **OCT+**.
2. Отправьте CC с внешнего контроллера — запишутся его номер и MIDI-канал.
3. Перейдите к нужной дорожке и редактируемому параметру.
4. Один раз поверните соответствующий K-регулятор, выбирая назначение.
5. Вернитесь в REC, настройте пределы и сохраните проект.

| REC-управление | Действие |
| --- | --- |
| SELECT | Выбор макроса; по четыре строки на странице |
| ALGORITHM | Включить/выключить |
| K1 | **RNG** (непрерывный диапазон) / **TGL** (два значения) |
| K2/K3 | Минимум/максимум или A/B, **0–127** |
| K4 | Обратное направление |
| OCT− | Запрос удаления; **OCT+** подтверждает, OCT− отменяет |

**Y** — включён, **N** — выключен, **S** — временно приостановлен, пока целевой движок отсутствует. При возвращении движка макрос снова работает. **Номер CC, канал и назначение нельзя редактировать**: удалите и создайте заново. Несколько макросов могут принимать один CC/канал и менять разные параметры.

### Отдельная функция MIDI Learn

Глобальный **MIDI Learn** имеет **32 собственных изученных назначения** вне REC. Для обучения откройте **HOME (удерживать) → MIDI → LEARN**, выберите параметр и переместите регулятор внешнего контроллера. Эти назначения не являются проектными макросами REC.

### Специальные MIDI CC

| Команда | Действие |
| --- | --- |
| CC88 / CC89 / CC90 | Временно изменить RX для T1 / T2 / T3 |
| CC85 | Слабо рандомизировать параметры мелодического звука |
| CC86 | Сильно рандомизировать их |
| CC87 | Восстановить последние сохранённые параметры |

**CC88–90:** значение **0–63 = RX канал 2**, **64–127 = RX канал 1**, на любом входящем MIDI-канале. Сохранённый проект не меняется, и его повторная загрузка возвращает исходные RX.

**CC85–87:** применяются на **канале 13 для T1, 14 для T2, 15 для T3**. **64–127 запускает** команду, **0–63 повторно готовит**. Барабанные движки не затрагиваются. CC87 не прерывает уже звучащие ноты, если движок не был заменён.

## 6. EQ, проекты и живые функции

**GLO → MIX → EQ** — общий трёхполосный эквалайзер перед эффектами: **LOW 50 Гц**, **MID 700 Гц**, **HIGH 10 кГц**, каждый **±15 дБ**. Это не EQ отдельных дорожек.

В **SAVE** сохраняются звуки и проекты: дорожки, MIDI, зоны, строй, макросы, эффекты. **SAVE → LIBRARY → TOOLS**: **K1 INIT SOUND**, **K2 CLEAR SLOT** (удаление после подтверждения), **K3 NEW PROJECT**, **K4 CPU TEST**.

**Live Recall:** удерживайте REC, затем нажимайте **FX / SEL / ENV / LFO** для проектов **1 / 2 / 3 / 4**. Снова удерживайте REC для выхода.

**PANIC:** удерживайте **GLO** и нажмите **OCT−**. Звучащие голоса, эффекты и sustain сбрасываются без удаления проекта.

Перед сменой прошивки сохраните полную копию проектов, пресетов и настроек через [MASHINA web editor](../webapp/editor/). Для установки используйте [инсталлятор](../webapp/installer/).

### Общий трёхполосный EQ

| Полоса | Частота | Диапазон |
| --- | --- | --- |
| LOW | **50 Гц** | −15…+15 дБ |
| MID | **700 Гц** | −15…+15 дБ |
| HIGH | **10 кГц** | −15…+15 дБ |
| ON | Включить / обойти EQ | — |

В **GLO → MIX → EQ** это **один общий EQ перед эффектами**, а не индивидуальный эквалайзер для каждого трека. Для дальнейшей обработки используйте FX и посылы. Сохраните проект.

### Сохранение и библиотека

| SAVE → LIBRARY → TOOLS | Действие |
| --- | --- |
| K1 | **INIT SOUND** — исходные параметры звука |
| K2 | **CLEAR SLOT** — удалить выбранный слот после подтверждения без возможности восстановления |
| K3 | **NEW PROJECT** — создать проект |
| K4 | **CPU TEST** — проверить нагрузку |

Проект хранит RX, зоны, строй, макросы, звуки и эффекты. Загрузка другого проекта без сохранения может потерять несохранённые изменения.

### Live Recall

**Долго удерживайте REC**, затем коротко нажимайте **FX / SEL / ENV / LFO**, чтобы открыть проекты **1 / 2 / 3 / 4**. Ещё одно долгое удерживание REC выходит из режима. Старые ноты останавливаются при смене проекта, но хвосты задержки и реверберации могут завершиться естественно.

### PANIC и резервные копии

**Удерживайте GLO и нажмите OCT−**, чтобы мгновенно заглушить голоса и эффекты и очистить удержанные ноты и sustain. На экране отображается PANIC MODE, пока удерживается GLO. **Проект не удаляется.**

Перед прошивкой или возвратом к старой версии сохраните **полную копию проектов, пользовательских пресетов и настроек**. Экспорт одного звука не является полной копией устройства. Используйте [MASHINA web editor](https://mishamashinamm.github.io/mashina-fm1-fw/webapp/editor/) для резервного копирования и [установщик](https://mishamashinamm.github.io/mashina-fm1-fw/webapp/installer/) для изменения прошивки.

## 7. Примеры для сцены

**Два тембра слоями:** T1 и T2 на RX 1, одинаковые ZONES, разные синтезаторы и панорама.

**Разделение клавиатуры:** один RX-канал, неперекрывающиеся MIN/MAX.

**Смена по velocity:** T1 1–80, T2 81–127, один канал и диапазон нот.

**Один регулятор — много параметров:** создайте несколько REC-макросов с тем же CC и каналом, но разными целями.

**Внешние барабанные пэды:** RX на MIXER, ноты на SEQ, velocity и choke на PLAY.
