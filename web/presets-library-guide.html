Connect and prepare

Use this manager with an already initialized MASHINA 32+32 FM1 and a desktop Chrome or Edge browser. It does not install firmware or initialize storage. For a downloaded ZIP, extract all files into one folder, open a terminal in that folder, run python3 -m http.server 8000 and open http://localhost:8000/. Keep the server running while using the library.

  1. Stop playing. Save any edited sound that you want to keep as a USER preset. A reference-based backup cannot capture a modified, unsaved sound as an independent patch.
  2. Click Connect FM1, then BACKUP → Current device backup → Backup complete FM1.
  3. Keep the downloaded JSON. Click Verify saved complete backup and choose that exact file. The header shows whether writes are unlocked.

During a centered operation dialog, do not disconnect USB, play or change controls on the FM1, or leave the page. Wait for completion and acknowledge the result. Every successful write automatically verifies the complete read-back, downloads an updated backup and keeps writes unlocked. Keep those files; you do not need to import them again between USER, LIBRARY and PROJECTS operations. Reconnection, unexpected device changes or a failed transfer lock writes until you capture and manually verify a new complete backup. The fresh pre-write comparison remains mandatory for every transfer.

Offline collections and performance files

The right column is a paged source list. Search by name, filter by engine/source, and import multiple JSON files into an independent collection. Drag device slots into the list, click + beside a sound, or use Add device sounds/projects. Remove entries with −. Save collection exports only the collected records, not every factory or device source shown in All sources. The collections are not limited to 32 slots and are kept independently of the FM1; save the JSON before closing the page. Imports merge exact duplicates while preserving different sound variants.

Drag sounds onto the left-hand numbered slots. Drag an existing slot onto another to swap or move its staged sound; orange rows indicate pending edits. Drag an offline project onto any section of a destination project to stage all four A–D sections (including empty ones); drag an A–D chip to stage only that section. Projects retain numeric preset references. Check the required USER presets and LIBRARY sounds before applying.

BACKUP → Performance file → Save complete performance exports the base device snapshot plus all pending USER, LIBRARY and project edits, current live references and settings. Select an existing complete backup and Open source offline to arrange it without a device. Reopen the resulting file in the complete restore panel to load it into an initialized FM1. No USB write occurs during drag/drop or export.

USER · 001–032

Editable sounds stored on FM1. Drag sounds to empty or occupied slots. Drag an existing slot onto another to move or swap the sounds. Slot numbers keep their project references; currently loaded sounds can be replaced and the live performance reloads after writing. Clearing a referenced USER slot is refused if it would leave a missing sound.

  1. Under Available presets, use Import JSON, or choose a source from the connected device or factory catalog.
  2. Drag a source sound onto a numbered USER slot, or expand Manual selection / fixed-slot import and choose source and destination. Alternatively, Queue all imported sounds skips exact duplicates and fills available empty slots.
  3. Review the USER write queue, click Restore queued USER sounds and confirm.

Export device USER sounds saves the complete stored sound records, including applicable drum/FM6 companions. It does not include projects or global settings.

LIBRARY · 033–064

32 factory-backed positions; overrides can be installed without reflashing. All 107 factory source sounds are available in the packaged catalog.

  1. Drag a sound from the right-hand list onto a numbered LIBRARY slot, or use manual selection. For an existing override, Queue factory reset returns the position to its compiled factory sound.
  2. Use Queue imported slot mapping only for packs whose saved positions are the intended LIBRARY destinations. Review the queue.
  3. Click Apply queued LIBRARY changes and confirm.

Changing a preset changes what every referencing section loads. The confirmation lists affected project sections. No separate permission checkbox is needed. Currently loaded LIBRARY presets can also be replaced or reset. The live performance is reloaded after writing, preserving its track references and settings; stop playing during the transfer.

Export device LIBRARY overrides exports stored overrides, not compiled factory fallbacks.

PROJECTS · 8 × A–D

Each section stores track preset references and project settings, not independent copies of its sound patches. Save the sounds first.

  1. Export device projects creates a projects-only JSON.
  2. Import JSON shows the imported and device sections. Choose changed sections individually or click Select changed sections. Empty source sections can clear selected occupied destinations.
  3. Restore selected project sections applies the selection after confirmation. Required USER references must already exist. Recall the section on FM1 to hear it.

Project-only restoration does not install sound records. Preserve matching sound packs or a complete backup for portable projects.

BACKUP · whole device

A complete logical backup contains the supported USER and LIBRARY records, 32 project sections, current performance and settings. It is not a raw flash dump or firmware installer.

  1. Capture and verify the current target backup first.
  2. Under Restore a complete backup, choose the source JSON.
  3. Review the changes. Restore complete FM1 may overwrite or clear stored slots and change the current performance. Click RESTORE in the confirmation dialog only if the listed changes are intended; CANCEL makes no changes.
  4. Keep both the original target backup and the new verified read-back. A live restore becomes an unsaved performance rather than overwriting a stored section.

Do not use this operation to migrate a legacy firmware backup. The manager requires the same supported reference-only layout; legacy USER extraction is a separate offline tool.

When a transfer is blocked or fails

  • Device changed since verified backup: the safety check found a difference before writes. Capture and verify a new target backup, review the intended changes again.
  • Unsaved sound / backup cannot be captured: save or reload the relevant preset before backing up; do not discard edits you want to keep.
  • STOP after acknowledged operations / failed read-back: some changes may already be stored. Keep all JSON files, including any automatically downloaded diagnostic read-back. Do not retry automatically, initialize or reflash. Inspect the actual state before deciding on recovery.

The advanced lab is for offline inspection, extraction and experimental diagnostics. Disconnect the manager before opening it. Its legacy and emulator JSON formats are not interchangeable with the physical-device full backup.

Experimental initialized-device workflow. No public first-install authorization. Keep your original backups outside the browser.
