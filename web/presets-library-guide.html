Connect and prepare

Use this manager with an already initialized MASHINA 32+32 FM1 and a desktop Chrome or Edge browser. It does not install firmware or initialize storage. For a downloaded ZIP, extract all files into one folder, open a terminal in that folder, run python3 -m http.server 8000 and open http://localhost:8000/. Keep the server running while using the library.

  1. Stop playing. Save any edited sound that you want to keep as a USER preset. A reference-based backup cannot capture a modified, unsaved sound as an independent patch.
  2. Click Connect FM1, then BACKUP → Current device backup → Backup complete FM1.
  3. Keep the downloaded JSON. Click Verify saved complete backup and choose that exact file. The header shows whether writes are unlocked.

During a centered operation dialog, do not disconnect USB, play or change controls on the FM1, or leave the page. Wait for completion and acknowledge the result. Any successful write downloads a new full backup; verify that new file before the next write. Reconnecting invalidates verification.

USER · 001–032

Editable sounds stored on FM1. Selective restoration fills empty, unreferenced slots only.

  1. Under Sound source, use Import sound pack (.json), or choose a source from the connected device or factory catalog.
  2. Choose Source sound and Destination, then Add to USER queue. Alternatively, Queue all imported sounds skips exact duplicates and fills available empty slots.
  3. Review the USER write queue, click Restore queued USER sounds and confirm.

Export device USER sounds saves the complete stored sound records, including applicable drum/FM6 companions. It does not include projects or global settings.

LIBRARY · 033–064

32 factory-backed positions; overrides can be installed without reflashing. All 107 factory source sounds are available in the packaged catalog.

  1. Choose or import a Source sound, choose a Destination and click Add to LIBRARY queue. For an existing override, Queue factory reset returns the position to its compiled factory sound.
  2. Use Queue imported slot mapping only for packs whose saved positions are the intended LIBRARY destinations. Review the queue.
  3. Click Apply queued LIBRARY changes and confirm.

Changing a preset changes what every referencing section loads. Saved project references are protected unless Allow changes to sounds used by saved projects is enabled. Currently loaded references remain protected for selective LIBRARY operations; load an unaffected performance and capture a fresh backup before replacing one.

Export device LIBRARY overrides exports stored overrides, not compiled factory fallbacks.

PROJECTS · 8 × A–D

Each section stores track preset references and project settings, not independent copies of its sound patches. Save the sounds first.

  1. Export all projects creates a projects-only JSON.
  2. Import projects JSON shows the imported and device sections. Choose changed sections individually or click Select changed sections. Empty source sections can clear selected occupied destinations.
  3. Restore selected project sections applies the selection after confirmation. Required USER references must already exist. Recall the section on FM1 to hear it.

Project-only restoration does not install sound records. Preserve matching sound packs or a complete backup for portable projects.

BACKUP · whole device

A complete logical backup contains the supported USER and LIBRARY records, 32 project sections, current performance and settings. It is not a raw flash dump or firmware installer.

  1. Capture and verify the current target backup first.
  2. Under Restore a complete backup, choose the source JSON.
  3. Review the changes. Restore complete FM1 may overwrite or clear stored slots and change the current performance. Click RESTORE in the confirmation dialog only if the listed changes are intended; CANCEL makes no changes.
  4. Keep both the original target backup and the new verified read-back. A live restore becomes an unsaved performance rather than overwriting a stored section.

Do not use this operation to migrate a legacy firmware backup. The manager requires the same supported reference-only layout; legacy USER extraction is a separate offline tool.

When a transfer is blocked or fails

  • Device changed since verified backup: the safety check found a difference before writes. Capture and verify a new target backup, review the intended changes again.
  • Unsaved sound / backup cannot be captured: save or reload the relevant preset before backing up; do not discard edits you want to keep.
  • STOP after acknowledged operations / failed read-back: some changes may already be stored. Keep all JSON files, including any automatically downloaded diagnostic read-back. Do not retry automatically, initialize or reflash. Inspect the actual state before deciding on recovery.

The advanced lab is for offline inspection, extraction and experimental diagnostics. Disconnect the manager before opening it. Its legacy and emulator JSON formats are not interchangeable with the physical-device full backup.
